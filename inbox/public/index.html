Especificación de la API REST Externa

Cualquier sistema externo (ERP, CRM, servicio de facturación o backend) puede enviar contenidos HTML hacia el inbox del usuario y activar una notificación push en sus dispositivos.

Método & URL Encabezados (Headers) Descripción
POST /api/inbox/send Content-Type: application/json Crea el elemento en el Inbox del usuario en Firestore y envía la Notificación Push por FCM a todos sus dispositivos activos.
Parámetros del Request Body (JSON)
Campo Tipo Requerido Descripción
userEmail String Sí (o userId) Correo electrónico del usuario destinatario registrado en Firebase Auth.
userId String Opcional UID del usuario en Firebase Auth (alternativa a userEmail).
title String Sí Título del elemento que se listará en el Inbox del usuario.
html String Sí Contenido HTML completo que el usuario visualizará al hacer clic en el elemento.
pushTitle String Sí Título que se mostrará en el banner de la Notificación Push del sistema operativo / navegador.
pushBody String Sí Mensaje / texto descriptivo de la Notificación Push.
Respuesta Exitosa (HTTP 201 Created)

Configuración de Firebase

Configura aquí las credenciales web de tu proyecto de Firebase. Se guardarán en el almacenamiento local de tu navegador.

Obtenla en Firebase Console > Settings > Project settings > Cloud Messaging > Web configuration > Key pair.
Nota para el Servidor (Backend): Para habilitar el envío de push desde el servidor, recuerda colocar tu archivo serviceAccountKey.json descargado de Firebase en la raíz del proyecto.
