Versión de Inspire

Actualiza un ambiente a otra versión publicada en Azure Container Registry.

Se descargan las imágenes de la nueva versión (varios GB) y, si el ambiente está en ejecución, se reinicia con ellas. Al arrancar, Inspire migra sus bases de datos: no se puede regresar a la versión anterior con los mismos datos. Crea un respaldo antes en Almacenamiento.

Firebase para Push Notifications Inbox

Tu propio proyecto de Firebase para el servicio opcional Push Notifications Inbox. Se guarda solo en este equipo. En el proyecto deben estar habilitados Authentication (Email/Password), Firestore y Cloud Messaging.

Firebase Console > Configuración del proyecto > Cuentas de servicio > Generar nueva clave privada. Pega el JSON completo.
Configuración del proyecto > General > Tus apps > app web. Puedes pegar el bloque const firebaseConfig = {...} tal cual.
Configuración del proyecto > Cloud Messaging > Certificados push web > Par de claves.
Si ya está configurado, deja en blanco lo que no quieras cambiar. Al guardar, los ambientes en ejecución con Push Notifications Inbox lo reinician con la nueva configuración.

Quadient Cloud para Digital Advantage Inbox

Aplicación de Quadient Cloud Digital Services a la que entran Digital Advantage Inbox y Banca en línea. Sus usuarios son cuentas de Quadient Cloud: la aplicación debe tener un almacén de usuarios con Inspire Authentication y autorregistro para crear cuentas desde el caso de uso.

Quadient Cloud > Digital Services > Applications: despliega los detalles de la aplicación. Al guardar, los ambientes en ejecución con este caso de uso lo reinician con la nueva configuración (tarda unos segundos).

Banca en línea

Estados de cuenta mensuales del caso de uso Banca en línea.

Depende de Quadient Cloud para Digital Advantage Inbox: usa la misma aplicación, los mismos usuarios y el mismo login. Configura primero ese apartado.
Banca en línea muestra como estados de cuenta solo los documentos con este metadato (por ejemplo DocType = accstt). Distingue mayúsculas y minúsculas. Deja el metadato vacío para mostrar todos los documentos. Al guardar, los ambientes en ejecución con Banca en línea la reinician con la nueva configuración (tarda unos segundos).
