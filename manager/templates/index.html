Firebase para Push Notifications Inbox

Tu propio proyecto de Firebase para el servicio opcional Push Notifications Inbox. Se guarda solo en este equipo. En el proyecto deben estar habilitados Authentication (Email/Password), Firestore y Cloud Messaging.

Firebase Console > Configuración del proyecto > Cuentas de servicio > Generar nueva clave privada. Pega el JSON completo.
Configuración del proyecto > General > Tus apps > app web. Puedes pegar el bloque const firebaseConfig = {...} tal cual.
Configuración del proyecto > Cloud Messaging > Certificados push web > Par de claves.
Si ya está configurado, deja en blanco lo que no quieras cambiar. Al guardar, los ambientes en ejecución con Push Notifications Inbox lo reinician con la nueva configuración.

Quadient Cloud para Digital Advantage Inbox

Aplicación de Quadient Cloud Digital Services a la que entra el caso de uso Digital Advantage Inbox. Se guarda solo en este equipo. La aplicación debe tener habilitada la autenticación Integrated Server-Side Authentication.

Quadient Cloud > Digital Services > Applications: despliega los detalles de la aplicación.
Digital Services > Authentications > Integrated Server Side Authentication > Edit > generar llave. Solo la usa el servidor del caso de uso; nunca llega al navegador. Déjalo en blanco para conservar la guardada.
Usuario Contraseña Subject

Sin usuarios. Agrega al menos uno.

Usuario y contraseña son solo para entrar a la app. El subject es el owner (userId) de los documentos en Digital Services: cada usuario ve los documentos públicos y los suyos. Si lo dejas vacío, se usa el nombre de usuario.
Al guardar, los ambientes en ejecución con este caso de uso lo reinician con la nueva configuración (tarda unos segundos).
