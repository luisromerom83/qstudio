Firebase para Push Notifications Inbox

Tu propio proyecto de Firebase para el servicio opcional Push Notifications Inbox. Se guarda solo en este equipo. En el proyecto deben estar habilitados Authentication (Email/Password), Firestore y Cloud Messaging.

Firebase Console > Configuración del proyecto > Cuentas de servicio > Generar nueva clave privada. Pega el JSON completo.
Configuración del proyecto > General > Tus apps > app web. Puedes pegar el bloque const firebaseConfig = {...} tal cual.
Configuración del proyecto > Cloud Messaging > Certificados push web > Par de claves.
Si ya está configurado, deja en blanco lo que no quieras cambiar. Los ambientes en ejecución toman los cambios al reactivarlos.
